Módulo 03 · HTML · CSS · JS · Claude AI

Creación de recursos digitales complementarios con HTML + CSS + JavaScript por medio de Claude

Diseña y construye recursos interactivos para tus estudiantes usando inteligencia artificial como copiloto. Sin experiencia previa en programación requerida.

1
¿Qué es Claude y cómo usarlo para crear recursos?
🎯
Objetivo

Comprender el funcionamiento básico de Claude como asistente de IA para la generación de código y recursos digitales educativos, y realizar las primeras interacciones productivas.

📚
Aprendizaje esperado

Las y los docentes formularán prompts efectivos en Claude para generar código HTML funcional, entenderán la estructura básica de una página web y podrán solicitar ajustes y mejoras al asistente.

📋
Instrucciones
  1. Accede a claude.ai y crea una cuenta gratuita.
  2. Escribe el siguiente prompt de prueba: "Crea una página HTML simple con un título, un párrafo de bienvenida y un botón que muestre una alerta al hacer clic."
  3. Copia el código generado y ábrelo en tu navegador (guárdalo como archivo .html).
  4. Pide a Claude que modifique el color del botón y el texto del título.
  5. Reflexiona: ¿Cómo describirías una actividad interactiva para tus estudiantes en términos de código?

2
Creando tu primer recurso interactivo para estudiantes
🎯
Objetivo

Producir un recurso digital educativo completo y funcional (quiz, infografía interactiva o actividad de emparejamiento) usando Claude como asistente de desarrollo.

📚
Aprendizaje esperado

Las y los docentes construirán un recurso HTML interactivo propio, adaptado a su asignatura y nivel educativo, listo para ser compartido con estudiantes vía enlace o archivo.

📋
Instrucciones
  1. Elige el tipo de recurso que necesitas: quiz de opción múltiple, actividad de ordenar pasos, o mapa conceptual interactivo.
  2. Redacta un prompt detallado para Claude describiendo: tipo de recurso, asignatura, nivel, número de preguntas/elementos y estilo visual.
  3. Itera con Claude al menos 3 veces pidiendo mejoras: colores, instrucciones, retroalimentación inmediata, etc.
  4. Guarda el archivo HTML final y pruébalo en distintos navegadores.
  5. Comparte el archivo con un colega para recibir retroalimentación pedagógica.
