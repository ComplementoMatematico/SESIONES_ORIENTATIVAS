Creación de sitio web gratuito + formulario interactivo + evaluación diagnóstica y de cierre

Lleva tu trabajo al siguiente nivel: publica tu curso en la web de forma gratuita, diseña formularios interactivos de cierre y construye instrumentos de evaluación para tus estudiantes.

1
Publicación de sitio web gratuito con GitHub Pages o Netlify
🎯
Objetivo

Publicar los recursos HTML creados en un sitio web accesible públicamente de forma gratuita, sin necesidad de pagar hosting ni dominio, usando plataformas como GitHub Pages o Netlify.

📚
Aprendizaje esperado

Las y los docentes publicarán al menos un recurso HTML en internet mediante una plataforma gratuita y compartirán el enlace con sus estudiantes.

📋
Instrucciones: Opción A — Netlify (más fácil)
  1. Accede a netlify.com y crea una cuenta gratuita con tu correo.
  2. En el panel, busca la opción "Deploy manually" o "Sites → Add new site → Deploy manually".
  3. Arrastra y suelta tu carpeta con los archivos HTML directamente en la zona indicada.
  4. Netlify generará un enlace automáticamente (ej: tu-nombre.netlify.app).
  5. Copia y comparte el enlace con tus estudiantes.
📋
Instrucciones: Opción B — GitHub Pages
  1. Crea una cuenta en github.com.
  2. Crea un nuevo repositorio público con el nombre mi-curso-sedpem.
  3. Sube tus archivos HTML al repositorio (botón "Add file → Upload files").
  4. Ve a Settings → Pages y selecciona la rama main como fuente.
  5. Tu sitio estará disponible en tuusuario.github.io/mi-curso-sedpem.

2
Formulario interactivo de cierre de sesión
🎯
Objetivo

Crear un formulario interactivo de cierre que recoja la percepción, dudas y aprendizajes de las y los estudiantes al finalizar cada sesión, de forma digital y sin requerir cuenta.

📚
Aprendizaje esperado

Las y los docentes diseñarán y publicarán un formulario de cierre funcional usando Google Forms o un formulario HTML generado con Claude, accesible vía enlace o QR.

📋
Instrucciones
  1. Decide entre dos opciones: Google Forms (sin código) o formulario HTML con Claude (más personalizado).
  2. Si usas Google Forms: crea el formulario con las preguntas de cierre, activa la opción "Aceptar respuestas sin iniciar sesión" y genera el enlace o QR.
  3. Si usas Claude: pide a Claude: "Crea un formulario HTML de cierre de sesión con 5 preguntas de reflexión, una escala de satisfacción y un campo de comentarios libres. Estilo visual moderno."
  4. Publica el formulario en tu sitio web (módulo anterior) o compártelo directamente como enlace.
  5. Genera un código QR del enlace usando qr-code-generator.com para proyectarlo en el cierre de sesión.

3
Evaluación diagnóstica y de cierre para estudiantes
🎯
Objetivo

Diseñar instrumentos de evaluación diagnóstica (inicio) y de cierre (final) para las y los estudiantes, en formato digital interactivo, usando Claude y las herramientas aprendidas.

📚
Aprendizaje esperado

Las y los docentes producirán un par de instrumentos de evaluación (diagnóstica + cierre) adaptados a su asignatura, publicados en línea y listos para aplicar con estudiantes.

📋
Instrucciones
  1. Define los aprendizajes que quieres medir con cada instrumento (diagnóstica: conocimientos previos; cierre: aprendizajes adquiridos).
  2. Pide a Claude que genere ambos instrumentos en HTML: "Crea una evaluación diagnóstica de 8 preguntas de selección múltiple sobre [tema] para [nivel]. Que muestre el puntaje al finalizar y retroalimentación por pregunta."
  3. Repite el proceso para la evaluación de cierre, ajustando el nivel de complejidad.
  4. Publica ambos instrumentos en tu sitio web bajo una sección "Evaluaciones".
  5. Prueba los instrumentos tú mismo/a y ajusta según sea necesario antes de aplicarlos.
